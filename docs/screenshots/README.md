# Capturas locales de verificación

`local-desktop.png`, `local-team.png` y `local-mobile.png` son capturas reales de la
aplicación en Docker Compose durante la prueba por navegador del 9/11/2026. Los datos
temporales que aparecen fueron eliminados al terminar la prueba.

No constituyen evidencia de GKE ni reemplazan las capturas oficiales con reloj del
sistema y `gcloud config list`. Para la entrega se deben capturar los resultados en
la infraestructura real y completar `docs/EVIDENCIAS.md`.
